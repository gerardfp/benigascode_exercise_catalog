# Cuenta números

Se deben ir leyendo números hasta que se lea un 0. El programa debe mostrar la cantidad de números leídos antes del 0.

## Input

Una secuencia de N números.

0 <= 1 <= 10^7

## Output

Un entero indicando la cantidad de números leídos
