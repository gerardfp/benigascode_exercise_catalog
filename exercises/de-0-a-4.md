# De 0 a 4

Escriu un programa que imprimeixi els números de `0` a `4` inclusive. Cada nombre ha d'estar en una nova línia.

## Plantillas

```java
void main() {
    
}
```

## Solutions

```java
void main() {
    for (int i = 0; i <= 4; i++) {
        IO.println(i);
    }
}
```
