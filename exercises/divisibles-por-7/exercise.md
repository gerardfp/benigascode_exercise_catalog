# Divisibles por 7

A partir de una secuencia de números, decir si cada uno de ellos es divisible por 7 o no.

## Input

Una secuencia de (N) números terminada en 0.

0 <= N <= 10^7

## Output

Un "SI" o un "NO" por cada número leído.
