# Completa la declaració

Donada una variable, afegeix el tipus `int` i assigna-li el valor `123456`.

No oblidis el `;` al final de la sentència.

## Plantillas

```java
void main() {

    variable  // canvia aquesta linia

    IO.println(variable);
}
```

## Solutions

```java
void main() {
    int variable = 123456;
    IO.println(variable);
}
```
