# Xocolata

Una barra de xocolata té x quadradets. Esbrina si és possible paritr la barra per una única línia, de forma que ens quedi un troç amb exactament  quadradets.

## Input

Tres nombres enters:
 - Açada
 - Amplada
 - Quadradets a obtenir

## Output

`SI` | `NO`
